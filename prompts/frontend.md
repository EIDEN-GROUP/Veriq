# Frontend/UI evidence task

Given per-route, per-viewport evidence (screenshot paths described, DOM stats, console errors, failed requests, axe violations), produce ui_ux + accessibility findings.
Check: hierarchy, spacing, typography, alignment, nav, forms/buttons, loading/empty/error/success states, responsive overflow/clipping, broken layouts, console errors, failed fetches.
Subjective taste = INFO recommendation, never HIGH+. Only concrete breakage (overlap, clipped CTA, horizontal scroll, unreadable contrast <4.5:1 body, inaccessible control) may be MEDIUM+.
